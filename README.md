# کاریونیت — ابزار شبکه (carunit-network)

افزونه وردپرس برای اتصال به پنل‌های اکانت شبکه (مرزبان، پاسارگارد، مرزنشین، 3x-ui، هیدیفای، s-ui، WGDashboard، IBSng، میکروتیک، میرزا، ایلان، کانکتیکس و فروش دستی) با پشتیبانی از پل‌بان.

**نسخه فعلی:** 1.2.1

## نصب
فایل `carunit-network.zip` را از آخرین ریلیز دانلود و از «افزونه‌ها › افزودن › بارگذاری» نصب کنید.

- تغییرات: [CHANGELOG.md](CHANGELOG.md)
- راهنما: [GUIDE.md](GUIDE.md)

---
WordPress plugin connecting WooCommerce to VPN/network account panels, with Polban proxy support. Install the `carunit-network.zip` asset from the latest release.
