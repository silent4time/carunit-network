# کاریونیت — ابزار شبکه (carunit-network)

افزونه وردپرس/ووکامرس برای اتصال به پنل‌های اکانت شبکه (مرزبان، پاسارگارد، مرزنشین، 3x-ui، هیدیفای، s-ui، WGDashboard، IBSng، میکروتیک، میرزا، ایلان، کانکتیکس و فروش دستی)، ساخت خودکار اکانت پس از پرداخت، تمدید و مدیریت سرویس‌ها، با پشتیبانی از پراکسی پل‌بان.

**نسخه فعلی:** 1.2.5

## نصب
فایل `carunit-network.zip` را از [آخرین ریلیز](https://github.com/silent4time/carunit-network/releases/latest) دانلود و از «افزونه‌ها › افزودن › بارگذاری» نصب کنید.

- تغییرات: [CHANGELOG.md](CHANGELOG.md)
- راهنما: [GUIDE.md](GUIDE.md) و `polban-guide.pdf`
- تست پراکسی پل‌بان (خارج از وردپرس): `php tests/polban-proxy-test.php`
