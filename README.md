# کاریونیت — ابزار شبکه

افزونه وردپرس برای اتصال به پنل‌های اکانت شبکه (مرزبان، پاسارگارد، مرزنشین، ربکا، 3x-ui و ...) با پشتیبانی از **پل‌بان**.

**نسخه فعلی:** 1.3.0

## قابلیت‌ها

- ساخت خودکار اکانت بعد از پرداخت ووکامرس
- تمدید و مدیریت سرویس‌ها
- پشتیبانی از پل‌بان برای دور زدن محدودیت‌ها
- افزودن خودکار مبدأ پنل به allowlist پل‌بان (از نسخه ۱.۳.۰)

## نصب

1. فایل زیپ آخرین ریلیز را دانلود کنید.
2. در وردپرس از مسیر «افزونه‌ها → افزودن → بارگذاری افزونه» نصب کنید.
3. تنظیمات پل‌بان را در بخش تنظیمات افزونه وارد کنید.

## به‌روزرسانی پل‌بان

برای استفاده از قابلیت افزودن خودکار مبدأ، پل‌بان روی سرور را به‌روز کنید:

```bash
cd /home/polban
git pull origin main
# یا اگر با اسکریپت نصب شده:
sudo polban
```

سپس فایل `public/index.php` را بررسی کنید که endpoint `/v1/allowlist` وجود داشته باشد.
